# Nuitool Vision

## Promise

**มีแค่มือถือ ก็เริ่มสร้างเกม 3D ที่เล่นได้**

Nuitool is not a desktop game engine shrunk onto a phone. It is a creator experience designed around touch, contextual actions and progressive disclosure.

## Product principles

1. **Touch-first** — gestures and contextual panels before desktop-style inspector walls.
2. **Beginner-first** — people should create before they learn engine vocabulary.
3. **Easy first, powerful later** — advanced logic and plugins appear only when needed.
4. **Invisible complexity** — renderer, physics, navigation, optimization and telemetry belong behind creator language.
5. **Data-driven** — projects describe worlds, actors, behaviors and rules as portable data.
6. **Open foundation** — use strong open-source components behind adapters instead of rebuilding mature infrastructure.
7. **Monitor what you create** — the creator should explain what the game is doing and why something fails.
8. **AI-native, not AI-dependent** — AI may help translate intent into visible rules, but the project remains understandable and editable without AI.
9. **Mobile performance by default** — quality, streaming and asset budgets should adapt automatically.
10. **Create does not mean make every asset yourself** — asset libraries, creator packs and future marketplace systems should let different skills work together.

## Primary creation loop

```text
Create
  ↓
Play
  ↓
Observe
  ↓
Understand
  ↓
Improve
  ↓
Publish
```

## What a beginner should see

- World
- Add
- Logic
- Play

Not:

- Mesh
- Collider
- NavMesh
- State Machine
- Shader Graph
- Draw Calls

Those concepts may exist internally, but the default experience translates them into questions people already understand.

## North-star moment

A new user should be able to:

1. Open Nuitool on a phone.
2. Place an object.
3. Place a character.
4. Set the character to **Walk Around**.
5. Add **Talk when near**.
6. Press **Play**.
7. See the idea working immediately.

The long-term product is successful when the distance between **“I have an idea”** and **“I can play it”** becomes dramatically shorter.
